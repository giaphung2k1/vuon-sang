# Vườn Sang - Hạ Tầng Cảnh Quan

Dự án thiết kế giao diện website cho **Công ty TNHH Hạ tầng Cảnh quan Vườn Sang** - Đơn vị tiên phong trong lĩnh vực tư vấn, thiết kế, thi công và bảo dưỡng cảnh quan sinh thái bền vững.

## Các trang giao diện

1. **Trang chủ (`index.html`)**: Giới thiệu tổng quan, banner hero cao cấp, 4 dịch vụ cốt lõi, giải pháp cảnh quan, dự án tiêu biểu và CTA.
2. **Dự án của chúng tôi (`du-an.html`)**: Danh mục dự án với bộ lọc phân loại theo loại hình (Resort, Cafe, Đô thị, Nhà vườn, Nhà máy...).
3. **Giải pháp cảnh quan (`giai-phap.html`)**: Chi tiết 4 giải pháp chuyên sâu (Thiết kế, Thi công, Cung ứng, Bảo dưỡng).
4. **Về Vườn Sang (`gioi-thieu.html`)**: Hồ sơ năng lực, Tầm nhìn - Sứ mệnh - Giá trị cốt lõi, đội ngũ và hệ sinh thái đối tác.
5. **Chi tiết dự án (`du-an-chi-tiet.html`)**: Trang dự án Cafe & Tea Cây Dừa với thư viện ảnh thu nhỏ tương tác, bảng thông số kỹ thuật và hệ thống tab nội dung.
6. **Liên hệ (`lien-he.html`)**: Form đăng ký tư vấn trực tuyến, thông tin hotline/zalo/email/địa chỉ và bản đồ vị trí.

## Công nghệ sử dụng

- **HTML5 & Vanilla CSS3**: Thiết kế responsive, typography Google Fonts (`Playfair Display`, `Plus Jakarta Sans`).
- **JavaScript (ES6+)**: Xử lý tương tác chuyển tab, lọc danh mục dự án, thư viện ảnh thumbnail và điều hướng.
- **Tối ưu hiển thị**: Tương thích đa kích thước màn hình từ Desktop đến Mobile.

## Cách chạy dự án

1. Clone repository về máy:
   ```bash
   git clone https://github.com/giaphung2k1/vuon-sang.git
   ```
2. Mở file `index.html` trực tiếp trên trình duyệt hoặc chạy qua local web server (XAMPP, Live Server, v.v.).
